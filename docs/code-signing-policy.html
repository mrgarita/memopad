Code signing policy（コード署名ポリシー）

MemoPad の Windows 向けファイルへのコード署名について、署名するもの・ビルドのしかた・署名を承認する人・プライバシーをまとめます。 英語の枠内は、署名を提供する SignPath Foundation の条件に合わせた原文です。

Free code signing provided by SignPath.io, certificate by SignPath Foundation.

MemoPad のインストーラと本体は、SignPath.io が無料で提供するコード署名で、SignPath Foundation の証明書を使って署名します。

現在の状況（2026-10-31）
SignPath Foundation に申請する準備中です。v0.10.5 までのインストーラは署名していないため、初回の実行時に Windows SmartScreen の警告が出ることがあります（「詳細情報」→「実行」で続行できます）。 署名を始めたら、ここに最初の版を記載します。

署名するファイル

ファイル署名
インストーラ MemoPad-setup-<版>.exeMemoPad として署名する
本体 MemoPad.exe・MemoPad.dllMemoPad として署名する
.NET ランタイムのファイル作者（Microsoft）の署名のまま。MemoPad としては署名しない
本文のエディタ部品（Scintilla.dll・Lexilla.dll・Scintilla.NET.dll）ほかの作者のものなので、MemoPad としては署名しない
アンインストーラ unins000.exeInno Setup がインストール時に作るもので、署名しない

署名するファイルは、製品名が「MemoPad」、製品バージョンがその版の番号（例：0.10.5）であることを、署名のたびに確かめます。

ビルドと署名の手順

  • 配布するファイルは、公開リポジトリ（github.com/mrgarita/memopad）のソースから、GitHub がホストする Windows ランナーで自動的にビルドします（.github/workflows/build.yml）。
  • 署名の依頼は、リリースのたびに承認者が SignPath の画面で内容を確かめ、手で承認します。
  • できたインストーラは実機で動作を確かめてから、GitHub Releases で公開します。

役割と担当者

  • Committers and reviewers: mrgarita (repository owner)
  • Approvers: mrgarita
  • コミッター・レビュアー：ソースを変更できる人。コミッター以外からの変更（プル リクエスト）は、レビュアーが内容を確かめてから取り込みます。
  • 承認者：署名の依頼を承認する人。
  • 担当者は全員、GitHub と SignPath に 2 段階認証でサインインします。

プライバシー

This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it.

MemoPad は、利用者が指示しない限り、ほかのコンピューターやネットワークに情報を送りません。設定は利用者の PC の %APPDATA%\MemoPad\settings.json にだけ保存します。 同梱している .NET ランタイムと Scintilla も、MemoPad の中で通信は行いません。

インストールとアンインストール

  • インストーラは管理者権限なしで、利用者ごとにインストールできます。
  • 「プログラムから開く」の候補への追加と、右クリック メニューの「MemoPad で開く」は、インストールの途中の「追加タスクの選択」で内容を示し、外すこともできます。既定のアプリ（ダブルクリックで開くアプリ）は変えません。
  • アンインストールは、Windows の「設定」→「アプリ」→「インストールされているアプリ」の MemoPad から行えます。インストーラが作ったファイルとレジストリのキーを削除します（利用者の設定ファイルは残ります）。
